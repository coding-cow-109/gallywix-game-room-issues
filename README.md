# Gallywix's Game Room: bug reports & ideas

This is the public place to report problems with, or suggest ideas for, the **Gallywix's Game Room** World of Warcraft addon.

## How to report

1. Go to the [Issues tab](../../issues) and click **New issue**.
2. Pick **Bug report** or **Idea or suggestion**.
3. Fill in the short form.

You need a free GitHub account to open an issue.

**Before you post,** please search the existing issues first; someone may have already reported it. If so, add a 👍 or a comment there.

## Getting the addon

Download it from [CurseForge](https://www.curseforge.com/projects/1695155).
